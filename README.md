
## はじめに
15パズル（スライディングパズル）を遊べるソフトをつくりました。

このソフトを使用すると自分の好きな写真や画像を自動的にレトロな15パズルにして遊ぶことができます。

15pazzlev.py


## こんなことができます

・　好きな画像を読み込んでパズルを遊べます。

・　3x3（8パズル）／　4x4（15パズル）　／　5x5（24パズル）が遊べます。

・　読み込んだ画像をシャッフルしたのち、AUTOで解析機能（※）があります。
　※4x4と5x5ではAUTO機能無効**
　　**3x3（8パズル）**: AUTO機能が利用可能
　　**4x4（15パズル）**: 無効
　　**5x5（24パズル）**: 無効

・　.jpg .jpeg .png .gif .bmp対応です

## 動作環境
Pythonで作ってます。windows,macos,linux,Androidで動くとAIが言ってます。

## 使い方

1.　Pythonで生成しています。Pythonが動く環境で実行してください。

2.　スクリプトを実行:
    15pazzlev.py  をクリックすると起動します。

3.　ソフトに画像を読み込みます。

4.　シャッフルボタンを押してください。

## 作って初めて知るパズルのルール

AIで作るんだ。簡単だろう。実に気楽に思っていました。実際作るまでは。

ところが…作ってわかるそのむずかしさ。

スライディングパズルには「転倒数（inversion）」という概念があり、無作為にシャッフルすると約50%の確率で解けない状態になってしまう。

というルールを初めて知る。つまり読み込んだ画像を適当にシャッフルすると解けなくなる。そうだったのか。

簡単に完成するかと思っていたけど、4x4（15パズル）と5x5（24パズル）でAUTO機能を動作させたら　あっさり解くこともあれば長時間解けないこともあって、そこが修正できなかった。

ですから現在は　4x4（15パズル）と5x5（24パズル）でAUTOボタンは使えません！　むり！
